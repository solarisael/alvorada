# Chargebook

Charge is the visible budget for branching, delegation, acquisition, and heavy generation.

This file is a tuning surface first. Runtime enforcement can come later.

## Baseline Costs

- read or inspect local artifact: 0
- write or update local artifact: 0
- rebuild continuity window: 0
- rebuild long-term memory: 1
- scaffold repo surfaces: 2
- web fetch or remote lookup burst: 2
- broad repo-wide research pass: 3
- spawn delegated lane or child run: 5
- multi-lane or competitive branch: 8
