## Shipped

- **Pretext transition engine** — `src/scripts/pretext_transitions.js`. Frozen effect registry
  (`dust`: staggered per-fragment scatter/rotate/blur; `fog`: blur-drift out, condense in),
  `transition_pretext_content(root, next_html, { effect, on_swap, ... })`. WAAPI per fragment,
  durations × `--site_fx_motion_mult`, instant-swap path for reduced-motion / no-WAAPI / zero
  fragments, per-root generation counter for re-entrancy. `on_swap` hook fires at the content-swap
  moment so callers update root attributes before the new sentence first paints.
- **`reset_pretext_source(root)`** export added to `pretext_justify.js` — the module WeakMap
  otherwise replays the cached source forever after a content swap.
- **Footer sentence cycler** — `src/data/footer_sentences.js` (Sol-authorable per-phase row table:
  html + align + effect; nigredo keeps the hatred couplet as row 0; other phases fall back to
  shared), `footer.astro` rewritten (semantic `<footer>`, SSR row 0 for no-JS), runtime
  `src/scripts/footer_cycle.js` (12s timer, IntersectionObserver + document.hidden cost-gating,
  idempotent hydration via WeakMap keyed on node + phase — idiomorph preserves the footer node
  across page swaps, so attribute guards are unreliable and a phase change must retire/rebuild
  the cycle), alignment CSS in `footer.css`.
- **Nav semantics restored** — `<mantle>` → `<nav aria-label>` on desktop + mobile navbars
  (CSS keys on IDs; base.css block-reset was the only element-name selector; zero pixel change,
  verified). Footer root likewise semantic now.
- **Manual step arrows** (afternoon) — ‹ › buttons flank the footer sentence (rendered only with
  2+ rows), delegated click listener drives the same transition path; manual steps skip the
  visibility gates (a click IS the visibility proof) and re-arm the 12s timer.
  `previous_footer_index` exported + tested; live-verified both directions with align landing
  at the swap instant.
- **Text Transition Lab** — new section in `/codex/labs/test-texts` (per the standing rule:
  registered effects get sandbox coverage). Demo sentences live as authorable `<template
  data-sol-transition-lab-sentence>` rows in the markdown; `pretext_transition_lab.js` is a
